# Cold Resume

## Purpose

Restore a wider project frame after a long pause.

## Loader

> Use the block below as structured project-state reconstruction data for resuming this work after a gap.

## Seed

```text
CRP::COLD-RESUME | state=paused | world=[research paper on user-owned continuity layers in progress, terminology stabilized, comparison notes already collected] | active=restore the paper drafting context | constraints=[technical tone, practical language, no false memory claims] | memory=[CRP reconstructs working state, not identity] | last_result=problem statement and core distinctions established | next_action=write the methods and examples sections
```

## Notes

Cold resume blocks should carry more `world` and `memory` than hot resume blocks.
