# Fork

## Purpose

Branch from a shared base state into an alternate line of work.

## Loader

> The block below is a branch handoff. Preserve the shared base state and continue only the fork-specific work.

## Seed

```text
CRP::FORK | state=forked | world=[shared product-planning baseline preserved] | active=compare two storage strategies for offline continuity | last_result=base requirements stabilized | next_action=return branch-specific tradeoffs and implementation implications | lineage=main@baseline-01 | preserve=[core requirements, privacy constraints, evaluation criteria] | delta_goal=analyze the local-first branch against the managed-sync branch
```

## Notes

Fork blocks are useful when you want divergence without losing the common base state.
