# Recovery

## Purpose

Restore the last stable state after drift or degraded output quality.

## Loader

> The previous session drifted. Use the block below to restore the last stable working context.

## Seed

```text
CRP::RECOVERY | state=drifted | world=[long-running architecture review remains active] | active=restore precise terminology and task focus | constraints=[preserve structure, avoid extra claims, return to the agreed technical tone] | last_result=architecture options were stable before drift | next_action=resume from the last clean state | preserve=[system definition, core constraints, decision criteria] | problem=session drift introduced loose language and repetition
```

## Notes

Recovery blocks are best when they identify both the problem and the state that should be preserved.
