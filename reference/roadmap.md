# Roadmap

## Near Term

- publish a reproducible interoperability test plan
- add machine-readable JSON examples for all eight modes
- collect independent producer and consumer implementations
- record compatibility reports using the conformance template
- complete an external review of the v1 security and authority model

## Medium Term

- define optional provenance and integrity envelope conventions
- specify branch conflict and merge-resolution semantics
- publish reproducible loader-versus-no-loader evaluations
- measure reconstruction fidelity across model families
- collect empirical guidance on `TRANSPOSE` usage and failure cases
- evaluate size and token-budget guidance with real workloads

## Longer Term

- evaluate backward-compatible v1.1 additions from collected evidence
- collect external tooling integrations
- review whether interoperability evidence supports describing CRP as an adopted standard
