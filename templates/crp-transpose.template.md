# CRP Transpose Template

Loader:

> Use the block below as a continuity handoff for preserving the useful collaboration frame while starting a fresh topic.

Seed:

```text
CRP::TRANSPOSE | state=stable | active=apply the explicit collaboration preferences to the new topic | constraints=[do not infer traits that were not serialized] | last_result=the explicit collaboration preferences were recorded | next_action=start the fresh discussion using only the recorded preferences | preserve=[tone: direct and candid, pacing: brisk with short progress updates, depth: technical with concise explanations, collaboration style: evidence-first and proactive] | strip=[prior domain-specific facts and unfinished tasks]
```

Use this when the goal is to carry productive collaboration state into a new domain without carrying the old topic with it.

Replace the example values with concrete descriptions of the state to preserve. Category names such as `tone` or `depth` are not reconstructable by themselves.
