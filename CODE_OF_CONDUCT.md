# Code of Conduct

## Purpose

This repository exists to develop a technical protocol in a professional, evidence-driven way.

## Expected Behavior

- be respectful and direct
- criticize ideas, not people
- keep discussion technical and specific
- cite evidence when making strong claims
- accept correction when facts change

## Unacceptable Behavior

- harassment or personal attacks
- discriminatory language
- repeated bad-faith argument
- spam, trolling, or derailment
- hype framing that obscures the actual protocol

## Scope

This code of conduct applies to issues, pull requests, discussions, and other project communication channels.

## Enforcement

Project maintainers may remove comments, close threads, or restrict participation when behavior interferes with productive work.
